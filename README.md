## 学习功能

- 首页提供散点回归、主成分投影和 Logistic 曲线三种动态统计图示，可切换或暂停；系统减少动态效果时默认暂停。
- 左侧课程栏可收起或展开，收起偏好保存在当前浏览器。
- 按原书顺序阅读，使用本章目录定位知识点；在讲解与对应习题间切换。
- 搜索全部笔记，可按课程筛选；支持 `⌘K` / `Ctrl+K` 和键盘选取结果。
- 公式使用 KaTeX 排版，统计图由原始 TikZ 源码渲染，保留原有表格、代码及运行输出。
- 逐题展开解析，标记已掌握；复制代码到自己的 R 环境使用。
- 302 道选择题支持点击选项作答和保存选择。285 道按明确的原解析判分；5 道保留原解析中的条件或歧义提示；12 道原文、图表或答案待核实的题只记录选择，不编造对错。
- 2026-10-11 补充 170 道题（线性回归 50、多元分析 40、广义线性模型 80）：每章 10 道，接续原题号放在原题之后；线性回归第 1 章、广义线性模型第 8 章各新增一组。每题解析末尾注明来源与改编性质，可点击跳到该课程的“来源与选编依据”。
- 收藏章节、标记已读、继续上次阅读，支持 16–22 px 正文字号。

## 闯关与段位

- **闯关地图**（`#/arena`）：285 道已核实答案的选择题和 5 道条件判分题，共 290 道，按章节分成 53 关，每关 4–6 题。每章第一关直接开放，通关后解锁本章下一关。每关 3 颗心，答错扣一颗；正确率 100% 得三星，≥80% 两星，≥60% 一星。课程全部关卡通过后解锁“终极挑战”（随机 10 题）。12 道答案待核实的题不进入闯关。
- **每日挑战**：可选全部课程、某一门课或某门课的某一章，每天按日期和范围固定抽 5 题；每天首次完成 +40 XP，换范围再做只算练习；**错题复活赛**：重做答错的题，订正一题 +4 XP；**60 秒极速**：限时连答，记录个人最佳。
- **段位**：样本新手 → 均值学徒 → 方差行者 → 回归骑士 → 主成分术士 → 似然大师 → 统计宗师，前六级各分 Ⅲ/Ⅱ/Ⅰ。XP 来自首次作答（答对 +10、条件题 +8、答错 +2）、订正、标记掌握（+5）、读完章节（+30）、星星（每颗 +15）、成就（每枚 +50）、每日挑战和学习天数（每天 +10）。同一题只按首次作答计分，章节内作答与闯关共用记录。
- 16 枚成就徽章、连续学习天数、连击、晋级动画和可选音效（默认关闭）。系统设置“减少动态效果”时关闭彩带、浮动文字等动画。
- 闯关题目和共用资料来自 `public/data/arena-<课程>.json`，由 `scripts/import_notes.py` 与章节数据一起生成；一组题共用的案例材料只在同一题号系列内连续沿用。
- 适配电脑和手机，提供三份原 PDF 下载。

## 个人存档与排行榜

- 不登录也能使用全部功能，进度保存在当前浏览器的 `localStorage`。
- 点击右上角“登录存档”，用 **用户名 + 6 位 PIN** 创建或登录存档后，学习进度、闯关记录、XP、收藏会自动同步到云端，换设备登录即可继续；首次登录可选择把本机进度并入。两台设备同时修改时按版本号合并，不会互相覆盖。
- **排行榜**（`#/leaderboard`）按总 XP、星星、连续天数排名，也可按用户名（拼音）排序；可在存档设置中随时隐藏自己。榜单数字来自各自的学习记录，服务器只检查数值是否合理。
- 安全：PIN 以加盐 HMAC（服务器密钥）保存；同一账户连续输错 5 次锁定 15 分钟，同一网络地址每小时最多 20 次失败；禁止 123456、111111 等易猜 PIN。没有邮箱找回，忘记 PIN 无法恢复，可在存档设置中导出备份文件。可修改 PIN（其他设备需重新登录）或删除云端存档。
- 后端是 `server/` 中的 Cloudflare Worker + D1（`medstats-sync`）。由于 `*.workers.dev` 在中国大陆无法直接访问，网页优先连接阿里云函数计算（香港）上的中转函数 `server/relay/`，它把 `/api/` 请求原样转给 Worker，并凭共享密钥 `RELAY_KEY` 报告访问者 IP 用于限流；中转不可用时自动改连 Worker。两个地址都写在 `src/sync.js`。
- 更新中转：在 `server/relay/` 运行 `RELAY_KEY="$(cat ../.relay-key)" npx @serverless-devs/s@3.1.10 deploy -y`（需先用 `s config add` 配置只含 AliyunFCFullAccess 权限的 RAM 密钥；`.relay-key` 不入库，与 Worker 的 `RELAY_KEY` 密钥一致）。
- 本地开发：

```sh
cd server && npm ci
echo 'PIN_PEPPER="<64 位十六进制>"' > .dev.vars
npm run migrate:local && npm run dev          # http://127.0.0.1:8787
VITE_SYNC_API=http://127.0.0.1:8787 npm run dev   # 在仓库根目录
```

部署：`npx wrangler deploy`（表结构变化时先 `npm run migrate`；密钥用 `npx wrangler secret put PIN_PEPPER` 设置，不入库）。

## 本地运行

需要 Node.js 22.12 或更新版本，推荐 Node.js 24。

```sh
npm ci
npm run dev
```

```sh
python3 scripts/verify_content.py
node scripts/check_math.mjs
node scripts/check_interactions.mjs
npm run build
npm run preview
```

网页使用相对资源路径与哈希路由，可在 GitHub Pages 的仓库子路径下直接刷新或分享章节链接。所有公式字体、正文、图片及 PDF 都随站点一起发布，无需依赖外部 CDN。

## 目录与内容更新

```text
src/                  网页界面、阅读样式和公式处理
server/               个人存档与排行榜后端（Cloudflare Worker + D1）
notes/                三门课程最终 LaTeX 正文、宏与配图
public/data/          已转换的 36 份章节数据、目录及搜索索引
public/figures/       原图渲染结果与原笔记配图
public/pdfs/          三份原始总笔记 PDF
scripts/              内容导入、配图渲染和完整性检查
.github/workflows/    自动构建及 GitHub Pages 发布
```

直接修改界面后提交到 `main` 即会自动发布。修改笔记正文时，先同步 `notes/<课程>/content/` 中对应的 `.tex` 文件，然后重新转换：

```sh
python3 scripts/import_notes.py
python3 scripts/verify_content.py
node scripts/check_math.mjs
```

内容转换需要 Pandoc。若修改了 TikZ 统计图，再运行 `python3 scripts/render_figures.py`，它需要 XeLaTeX、Poppler 和 Pillow。`notes/<课程>/references.json` 保留原书引用编号；正文编号或标签变化时应根据新编译的 `main.aux` 更新。原 PDF 可替换 `public/pdfs/` 中对应文件。
